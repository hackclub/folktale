# Differences for Clubs

Hey there! If you've made your way to this page then you're probably doing Folktale as part of your school's Hack Club. The guide still mostly holds true, but there are a few key differences. **None of this applies if you aren't doing Folktale as part of a Clubs workshop**.

Alright, now the clubs-specific stuff. The Folktale guide covers how to get set up with Hack Club Spaces; maybe something that you've already done before. The guide coveres how to get signed up there using Hack Club Auth, but you may use your Clubs login. Also, use of Hackatime is not mandatory (though it's still really helpful for our review!).

The next few sections of the guide cover how to actually make your game, these hold consistent. However at the end, there is a page on submitting your project. Most of these instructions (setting up GitHub, running with Pyterm, the like) will hold the same. The only thing that's different is that you won't be using the submission form linked near the bottom of this page, rather you will be submitting within the Clubs platform.

Also, you will not be getting individually mailed stickers. We may send over a box of sticker sheets if a good chunk of a club completes Folktale, but the main rewards within the Clubs world will be Clubs Coins.

Now, make your way back to <a href="/guide/">the start of the guide</a>, learn Python, and build an awesome little game!
